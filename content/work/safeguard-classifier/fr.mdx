## Le problème

Modérer des conversations IA demande d'être rapide et nuancé. Les règles seules ratent le contexte ; un grand modèle seul est lent, coûteux et constitue un point de défaillance unique.

## Ce que j'ai fait

1. Étape 1 : règles regex et mots-clés, sans latence ajoutée.
2. Étape 2 : si rien ne correspond, un `openai/gpt-oss-safeguard-20b` local évalue la conversation sur GPU.
3. Si le GPU ou le modèle est indisponible, le service se replie sur les règles au lieu d'échouer.
4. Une petite API HTTP (`POST /classify`, `GET /health`) renvoie `{ violation, confidence }`, empaquetée avec Docker Compose.

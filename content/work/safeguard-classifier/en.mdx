## The problem

Moderating AI conversations needs to be both fast and nuanced. Rules alone miss context; a large model alone is slow, costly and a single point of failure.

## What I did

1. Stage 1: regex and keyword rules, with zero added latency.
2. Stage 2: if nothing matched, a local `openai/gpt-oss-safeguard-20b` scores the conversation on GPU.
3. If the GPU or the model is unavailable, the service falls back to rules only instead of failing.
4. A small HTTP API (`POST /classify`, `GET /health`) returns `{ violation, confidence }`, packaged with Docker Compose.
